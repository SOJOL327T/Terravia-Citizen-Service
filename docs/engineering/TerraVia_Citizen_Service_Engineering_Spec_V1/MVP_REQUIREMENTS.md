# TerraVia Citizen Service — MVP Requirements V1

## Must-have P0
- Create and authenticate TerraVia Person Identity.
- Link credentials without replacing source systems.
- Record evidence and provenance.
- Detect and case identity conflicts.
- Create scoped consent.
- Evaluate policy decisions.
- Prepare minimum-data packages.
- Execute authorized transfers through controlled adapters.
- Produce transfer receipts.
- Maintain security and audit trails.
- Global STOP ALL AUTOMATION.

## P1
- Application readiness.
- Service catalog.
- Adapter framework.
- Governed AI assistant.
- Human review workflow.

## MVP acceptance criteria
1. A person can create an identity without NID replacement.
2. At least one credential can be linked and source status shown.
3. Conflicting DOB claims create a conflict rather than overwrite.
4. A data request shows requester, purpose, fields and expiry.
5. No transfer occurs without required authorization/consent.
6. Receipt lists exactly what was transferred.
7. AI cannot directly write authoritative identity data.
8. STOP blocks automated transfers.
9. Every security-sensitive action is auditable.
10. External adapter failure cannot create false verification.
