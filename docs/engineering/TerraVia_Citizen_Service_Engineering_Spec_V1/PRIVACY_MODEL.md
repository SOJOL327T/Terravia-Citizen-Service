# TerraVia Citizen Service — Privacy Model V1

## Principles
Privacy by design, purpose limitation, data minimization, transparency, user control, retention limitation and secure deletion where applicable.

## Visibility domains
Personal, Household, Family/Branch, Organization/Service, Public. Every object has explicit visibility rules.

## Family privacy
Family membership does not grant access to private records. Event audiences are explicit. Living persons can restrict visibility of relationships and memories.

## Data lifecycle
Collect -> classify -> verify -> use for declared purpose -> retain according to policy -> archive/delete where permitted -> audit.

## AI privacy
AI receives minimum required context. Sensitive data is not exposed to models without policy authorization. AI outputs carry provenance and uncertainty.

## User controls
View activity, consent history, transfer receipts, connected services, sessions/devices, privacy settings and exportable personal/family data where permitted.
